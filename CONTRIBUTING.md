# Contributing

Bug reports and focused pull requests are welcome. For larger changes, open an
issue first so privacy, storage, and API-rate-limit implications can be
discussed.

1. Fork the repository and create a descriptive branch.
2. Install the runtime and development requirements from `backend/`.
3. Run `python -m pytest -q` before submitting a pull request.
4. Add tests for security- or privacy-sensitive behavior.

Use synthetic email addresses and findings only. Never commit API keys,
recovery tokens, webhook URLs, or real breach data.
